# W.S. 35-24-105. Grounds for refusal of application review.
(a) If the director determines that an application is unclear, incomplete or provides an insufficient basis on which to base a decision, the director shall return the application and provide a written description of the deficiencies in the
application to the applicant. The applicant may complete or revise and resubmit the application.
(b) The director may decline to review any application relating to arrangements already in effect before the submission of the application.
