# W.S. 22-24-315. Petitions; filing by sponsors.
(a) Petitions may be filed with the secretary of state if signed by a sufficient number of qualified registered voters as required by the Wyoming constitution.
(b) Petitions for an initiative shall be submitted to the secretary of state for verification within the eighteen (18) month period following the date the first set of petition forms are provided to the sponsors. Any petition not submitted within the eighteen (18) month period is void for all purposes.
